# Landschaft Constitution Index

This folder holds the methodological and procedural constitutions that govern Landschaft analysis workflows. Each constitution is a standalone authority document. Application code, prompts, and review flows must defer to these documents rather than inventing parallel methodology.

## How to use this index

1. Select the workflow constitution that matches the active Landschaft checkpoint.
2. Read the full constitution file before changing prompts, UI copy, or analysis logic.
3. Link new constitutions from this index when they are added to the repository.

## Primary external authorities

- Carys Swanwick, *Landscape Character Assessment: Guidance for England and Scotland* (Countryside Agency and Scottish Natural Heritage, 2002).
- Natural England, *An Approach to Landscape Character Assessment* (2014), which retains the 2002 four-step process.
- Council of Europe, *European Landscape Convention* (2000).
